Shared Worlds

Worlds with no dedicated server. Whoever is online and has the strongest machine hosts the world, and the host changes without kicking anyone. The world is stored here, so it is always safe and always current.

Join a world

  1. Install the Create Full Stack modpack (NeoForge 1.21.1) and make sure the mcmesh mod is in it. Both the modpack and the mod are in the pack download.
  2. Start the game. Pirated or premium accounts both work, Microsoft accounts sign in automatically.
  3. In the multiplayer menu add the server play.23012006.xyz, or open Shared Worlds from the title screen.
  4. Got an invite code from a friend? Press Redeem in Shared Worlds, paste it, then join the world from the list.

Host a world

Press Create in Shared Worlds to start a fresh shared world, or Convert to upload one of your singleplayer worlds. The first player in becomes host. If a stronger machine joins later it waits a few minutes, then takes over. The game shows a short switching screen and everyone reconnects automatically.

Good to know

  • The host plays on their own machine, so the world is as fast as their computer and connection.
  • Progress is saved to the gateway continuously, a crash costs seconds, not a session.
  • Voice chat and other mod channels are relayed through the gateway as well.
  • World admins manage members and mod rules in the web panel. Sign in with the code from the Shared Worlds screen.
